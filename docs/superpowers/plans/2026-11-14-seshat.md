# Seshat Implementation Plan

> Historical record. Written when the project was called Seshat; it was later renamed Anzu and parts of the design changed.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desktop app in Rust for Windows that detects the Kindle app's books, checks that Satsuoni's tool is the latest release and is compatible, runs it to unlock, and converts the result to EPUB with its own code.

**Architecture:** Cargo workspace with three crates. `seshat-kfx` reads DRM-free KFX and writes EPUB 3, with nothing Windows-specific. `seshat-core` detects Kindle, queries GitHub, decides compatibility, downloads and verifies the tool, runs it and works out the state of each book. `seshat` is the binary: GUI with `egui` and a `convert` subcommand.

**Tech Stack:** Rust 1.100 (2024 edition), `eframe`/`egui`, `rfd`, `ureq`, `serde`/`serde_json`, `sha2`, `zip`, `thiserror`. Versions: the latest stable that `cargo add` installs.

**Spec:** `docs/superpowers/specs/2026-11-14-seshat-design.md`

## Global Constraints

- License `GPL-3.0-or-later` in every `Cargo.toml`.
- No decryption code is written. Unlocking is always Satsuoni's archiver as an external process.
- Nothing is ever written, moved or deleted inside the Kindle content folder.
- The archiver only runs if the sha256 of the zip matches the `digest` from the GitHub API. Without a `digest`, it does not run.
- Doubtful compatibility, or compatibility that cannot be determined, means blocked.
- The Kindle app is only closed after explicit confirmation from the user.
- App data in `%LOCALAPPDATA%\seshat\`: `tool\<tag>\`, `unlocked\<ASIN>.kfx-zip`, `keys\seshat.k4i`, `settings.json`, `seshat.log`.
- Package family: `AMZNKindle.AmazonKindleReadingApp_m1sc522ngdk36`. Content in `%LOCALAPPDATA%\Packages\<family>\LocalState\Classic\Content\`.
- Releases: `GET https://api.github.com/repos/Satsuoni/DeDRM_tools/releases?per_page=5`, header `User-Agent: seshat`. The first element is used (all of them are `prerelease`).
- Interface text in Spanish, with correct accents, exactly as in the mockup.
- `seshat-kfx` does not depend on `seshat-core` or on Windows APIs.
- An unrecognised KFX element is skipped and logged; it does not abort the conversion.

## Review Focus

1. **No network, or GitHub returns 403 because of the rate limit.** Expected: unlocking blocked with a clear message; converting books that are already unlocked stays available. Test in Task 3.
2. **New release with executable names that do not follow the pattern.** Expected: `Compat::Unknown`, blocked. Test in Task 2.
3. **Kindle not installed, or installed with no books downloaded.** Expected: an empty screen that explains it, no panic. Test in Task 5.
4. **Title with characters that are illegal on Windows (`: ? * " < > |`) or too long.** Expected: sanitised file name and EPUB written. Test in Task 10.
5. **Truncated KFX, or KFX with an unknown Ion type.** Expected: a descriptive `Err`, never a panic or an infinite loop. Test in Tasks 7 and 8.
