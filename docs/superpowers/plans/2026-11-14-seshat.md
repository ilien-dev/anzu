# Seshat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App de escritorio en Rust para Windows que detecta los libros de la app Kindle, comprueba que la herramienta de Satsuoni es la última y es compatible, la ejecuta para desbloquear y convierte el resultado a EPUB con código propio.

**Architecture:** Workspace de Cargo con tres crates. `seshat-kfx` lee KFX sin DRM y escribe EPUB 3, sin nada de Windows. `seshat-core` detecta Kindle, consulta GitHub, decide compatibilidad, descarga y verifica la herramienta, la ejecuta y calcula el estado de cada libro. `seshat` es el binario: GUI con `egui` y subcomando `convert`.

**Tech Stack:** Rust 1.100 (edición 2024), `eframe`/`egui`, `rfd`, `ureq`, `serde`/`serde_json`, `sha2`, `zip`, `thiserror`. Versiones: la última estable que instale `cargo add`.

**Spec:** `docs/superpowers/specs/2026-11-14-seshat-design.md`

## Global Constraints

- Licencia `GPL-3.0-or-later` en cada `Cargo.toml`.
- No se escribe código de descifrado. El desbloqueo es siempre el archiver de Satsuoni como proceso externo.
- Nunca se escribe, mueve ni borra nada dentro de la carpeta de contenido de Kindle.
- El archiver solo se ejecuta si el sha256 del zip coincide con el `digest` de la API de GitHub. Sin `digest`, no se ejecuta.
- Compatibilidad dudosa o imposible de determinar equivale a bloqueado.
- La app Kindle solo se cierra tras confirmación explícita del usuario.
- Datos de la app en `%LOCALAPPDATA%\seshat\`: `tool\<tag>\`, `unlocked\<ASIN>.kfx-zip`, `keys\seshat.k4i`, `settings.json`, `seshat.log`.
- Familia del paquete: `AMZNKindle.AmazonKindleReadingApp_m1sc522ngdk36`. Contenido en `%LOCALAPPDATA%\Packages\<familia>\LocalState\Classic\Content\`.
- Releases: `GET https://api.github.com/repos/Satsuoni/DeDRM_tools/releases?per_page=5`, cabecera `User-Agent: seshat`. Se usa el primer elemento (todas son `prerelease`).
- Textos de la interfaz en español, con acentos correctos, tal como están en la maqueta.
- `seshat-kfx` no depende de `seshat-core` ni de APIs de Windows.
- Un elemento KFX no reconocido se omite y se registra; no aborta la conversión.

## Review Focus

1. **Sin red o GitHub devuelve 403 por límite de peticiones.** Se espera: desbloqueo bloqueado con mensaje claro; la conversión de libros ya desbloqueados sigue disponible. Test en Tarea 3.
2. **Publicación nueva con nombres de ejecutable que no siguen el patrón.** Se espera: `Compat::Unknown`, bloqueado. Test en Tarea 2.
3. **Kindle no instalada, o instalada sin libros descargados.** Se espera: pantalla vacía que lo explica, sin pánico. Test en Tarea 5.
4. **Título con caracteres ilegales en Windows (`: ? * " < > |`) o demasiado largo.** Se espera: nombre de archivo saneado y EPUB escrito. Test en Tarea 10.
5. **KFX truncado o con un tipo Ion desconocido.** Se espera: `Err` descriptivo, nunca pánico ni bucle infinito. Test en Tareas 7 y 8.
